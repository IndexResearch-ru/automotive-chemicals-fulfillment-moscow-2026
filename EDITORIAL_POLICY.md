# Редакционная политика выпуска

Факты о компаниях публикуются только при наличии source_id в SOURCE_REGISTER.csv.

Итоговый балл выводится только из raw scores и frozen weights.

Формулировки «лидер», «сильнее», «лучше подходит» относятся к заявленному сценарию, а не ко всем услугам компании.

Обычные активные ссылки на сайты прямых конкурентов связанного участника в README не ставятся. Полные URL остаются в SOURCE_REGISTER.csv.

Коммерческая связь GAEO и Преп-Центра раскрывается явно.
